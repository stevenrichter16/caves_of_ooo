# Sodden expedition: working prompts

## 1. Brainstorming prompt

Audit the live Sodden and Sumphold composition, exploration admission, native environmental hazards, crops, repairs, inventory transactions, saves and voxel presentation. Design three connected, discoverable destinations: a damaged works with real equipment and materials; a crossing offering costly dry travel and tempting wet shortcuts; an inhabited preparation stop improved by the player. Prefer existing mechanics with concrete consequences over new abstract meters. Preserve quiet wilderness, put residents close to Sumphold, and do not overwrite existing authored sites. Identify false premises before deciding. Give the journey an immediate payoff and a persistent reason to revisit. Use original Caves of Ooo fiction and art.

## 2. Design prompt

Turn the audit into an implementable contract. Name exact eligible addresses, content owners, costs, rewards, routes, failures, save/version behavior and visual states. Specify discovery in the world, ordinary player commands, environmental interactions and independent counterchecks. Distinguish actual mechanics from atmosphere. Design a small complete circuit with bounded content and no forced quest progression. Record source corrections, risks and scope cuts. Specify native EditMode and PlayMode verification, including what cannot be proven automatically.

## 3. Implementation prompt

Implement the approved design in SODDEN-EXPEDITION-DESIGN.md. First write tests and observe RED in Unity. Build native owner-based content, ordinary command routing, deterministic layouts, current-owner presentation and literal save persistence. Edit Objects.json surgically and compare parsed blueprints. Give every new C# file a fresh meta GUID. Run focused tests, adversarial counterchecks and relevant regression tests. Generate and inspect the original models, exercise a reviewed native scenario, then perform the four-question cold review. Fix significant issues, document remaining limitations honestly, update this living design, and commit with CLAUDE.md's template. Fetch/rebase and push main as already authorized. Do not enable normal-play BitLocker or expand unrelated features.
