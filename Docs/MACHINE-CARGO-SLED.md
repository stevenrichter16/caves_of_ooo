# Cargo sled: local hauling support

November 24, 2026. Bounded native and recorded Editor qualification complete. This increment
publishes the runtime and evidence; the next coherent Mac batch is pending.
This is one new capability in the next medium-depth batch, not three features
for its construction, installation and recovery. The portable screen and a
repairable crossing remain candidates, not selected shipped behavior.

The player already meets FallenBeam, HaulBarrel and other deliberately haulable
objects. Ordinary DragSystem follows the vacated cell, uses real load weight,
checks shared blockers and applies a Speed penalty. Carrying, dismantling and
existing paid freight remain alternatives. A reusable timber sled should make a
permitted local haul less slow, without making a heavy load weightless or
inventing universal cargo transport.

Qualified bounded contract: craft one singleton sled at an ordinary forge from
one iron spike, two salvaged timber and two knotflax cord. From beside a sound,
visible, unowned ordinary haulable load, place the same carried sled beneath it
for one action. The sled remains a physical nonsolid ground entity with pickup
disabled. New saved references identify the exact sled and load both ways. The
load keeps its mass and lift/haul eligibility; a valid sound sled halves only
the ordinary hauling Speed penalty. Its own weight contributes to the total
load. Existing hauling follows and blockers remain authoritative.

Only single-cell, nonliving, opted-in loads with no protected ownership, active
grip or incompatible installation qualify. No scenery conversion, pulling
capacity increase, skipped doorway, generic cross-zone hauling or capstan.
Existing ordinary local haulables supply the discovery opportunity; creation
does not alter cached settlements or regrant stock. Canonical material-culture
wood, iron and cord support mundane transport; no mystery or faction claim.

Only the shared successful hauling-follow path carries the same sled from its
previous ground cell to the exact load destination. A generic forced movement
event is insufficient: a shove must leave the sled behind. Independent movement,
damage or removal cannot leave a hidden free bonus. Sled recovery takes one
action, preserving identity; it remains recoverable beside a removed load.
Attach/retrieve refuse while either end is actively hauled. Refusal/cancel is
free. Existing saved DragPart fields remain unchanged; the shared validation
reconciles changed penalties by removing only the recorded applied delta.
TurnManager refreshes the link before speed grants energy; GetSpeed stays pure.
The sled adds six physical weight to its load, including while broken.

prevents slips, so a proposed generic bridge cannot claim new access or traction
without another real opportunity. Existing Reeds have no harvested fibre budget;
