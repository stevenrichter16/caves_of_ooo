# Examine discovery mockups

Generated on 2026-10-16 with the built-in `image_gen.imagegen` tool, one separately prompted image per subject. Ten mockups use [the experience-based Examine design](../EXPERIENCE-BASED-EXAMINE.md) and [the native field-ledger screenshot](../../Verification/ExamineLedger/final-well-1280x800.png) as their sources.

[Open the gallery](index.html) · [Download all ten PNGs](examine-discovery-10-images.zip) · [Exact prompt set](prompts.json)

These are design mockups showing hypothetical player experiences. No runtime game changes were made. Creature portraits are concept interpretations of the game's voxel style; object portraits follow existing identities. Generated surrounding HUD lettering is not a proposed change to skills or stats. All ten images were visually inspected for readable dialog content, portrait/subject match, distinct observation and inference, and no hidden numeric mechanics in Examine.

The prompt for each image is `commonPrompt` followed by its `images[].text`. `manifest.json` records original generated paths, copied filenames, dimensions and SHA-256 hashes. The original generated images remain in place.
