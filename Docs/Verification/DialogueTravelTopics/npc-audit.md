# NPC dialogue body and choice audit

Audit date: 2026-10-15. Scope is the runtime body decorators and choice injectors used by NPC dialogue, plus their authored conversation nodes and scenario callers. Source locations below identify the pre-fix evidence; line numbers may shift during the coordinating agent's topic split. This subtask ran no Unity tools and made no production changes before the native RED gate.

## How the mismatch reaches the screen

`ConversationManager.CurrentText` composes `LocalPeople`, `WorldTravellers`, `FirstHourGuidance`, then `SpreadDiscoveryReports` (`Assets/Scripts/Gameplay/Conversations/ConversationManager.cs:20`). Its choices are separately filtered from authored nodes, optionally relabeled by `FirstHourGuidance`, then extended by `RegionalGuidance`, `SpreadDiscoveryReports`, trade and attack (`ConversationManager.cs:198`). A source search of gameplay writers found no other runtime NPC text/choice injection path. Individual action and predicate implementations were checked for this routing boundary, not exhaustively re-audited for every gameplay transaction.

This separation is valid when both halves describe the same topic. The reported scribe screen did not: only historical report prose was appended, while settlement choices came first. Four named settlement coordinates matched the actual authored map. They were separate destinations, not misdirected buttons for the reports.

## Verification status and limits

Eight new tests were written before production: three expected local-label failures, two expected authored-resident-scope failures, and three unchanged-fallback controls. The coordinator's native `initial-red.xml` records 76 total cases, 49 passes and 27 expected failures across the combined task. All five NPC-audit failures and all three passing fallback controls were confirmed before these production edits.

The scoped `LocalPeople.PresentChoice` now shares its body eligibility helper and copies only the three affected choice labels. The coordinator owns its integration in `ConversationManager`. Both field-resident questions and introductions now acknowledge useful places/routes and a route farther afield; node IDs, actions, predicates and the three existing report offers are unchanged. The shared `FriendlyNPCs.json` villager prose and original reply labels remain untouched for fallback contexts.

The native `topics-green-ui-red.xml` run records 68 cases, 66 passes and two failures. Seven of these eight audit cases passed. The remaining local Start case reached and passed its new label/clone assertions, then failed an incorrect fixture assumption that every other authored choice must be visible: the real Start node contains a `MetChoir`-gated option. The fixture now requires each unrelated choice's original identity only when its real predicates permit it, and explicitly requires predicate-hidden choices to remain absent. No production correction was needed for this failure. The other failure in that run is the coordinator's expected hidden-shortcut UI RED. At this precommit review, the coordinator's broader native suite of 35 dialogue-related fixtures is still running; its terminal result has not yet been asserted here.

This audit is bounded source/content evidence with explicit counterexamples, not an exhaustive proof that every NPC story is contextually perfect. The coordinating agent owns Unity runs, final screenshots, living documentation and commits.
