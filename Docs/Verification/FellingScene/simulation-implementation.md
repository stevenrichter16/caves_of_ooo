## Native wildlife and supplemental harvestable scenery

The user expanded the scene to include other new sprites and creatures. This extension preserves the original 55 source owners and all 39 clearable components. It adds three native creatures: two GlasspaneFrog at (22,2) and (23,8), and one YellowfootWayfarer at (57,20). Existing blueprints supply passive wandering, HP, damage/death, frog flight and tortoise armor. Their existing animated actor sheets remain authoritative. No snake hostility, animal cargo behavior, artificial glow or new ecology mechanic is invented. CascadeFather was considered but excluded because the existing habitat predicate requires a real SprayPool, while the authored bank is ordinary dry ground beside water.

Three sparse supplemental objects use separate stable identities and existing native interactions: MushroomRing at (24,15) and (54,14), which harvest 2–4 edible Mushrooms and consume the source; and loose Tepuibone at (55,23), which uses normal inventory pickup/drop. The requested sprites are separate resources under `SceneArt/FellingSite/Art/extras`, not additions to the original source manifest. The presentation API exposes source dimensions/feet and resolves the actual world-owned entity, so taking a stone hides it and dropping it elsewhere moves the same visible object. The dressing identity cache is nonserialized and invalidates on zone entity changes.

`PopulationRevision` and `DressingRevision` are separate saved integer fields on the existing ground state Part. Each population occurs once on fresh generation or migration of an older scene. Death, harvest, pickup and removal do not cause respawns on re-entry or save/load. Missing blueprint/output content is refused before that population is partially staged or its revision consumed. Unknown saved occupants retain their positions; nearby eligible habitat is used when available. An entirely occupied habitat patch is skipped permanently for that revision, preserving existing structures without creating a later surprise spawn. Active old saves register new fauna with their restored TurnManager; inactive cached scenes wait for normal entry before being scheduled.
