## API and invariants
Optional CaptureSourceReceipts bool on population/container; SourceReceipt immutable snapshot with Zone, Revision, Owners, IsCurrent. Each build invalidates prior receipt, even no-op/failed source. Receipt reading consumes no RNG, runs no callback, creates no entity. New late builder(manager, composition, population, containers, excludedWayhouseZoneID) Priority4300. Selection helper has IsEligible/Select with same manager/id/excluded string; kinds cargo/gleanings/shelter or empty, deterministic one-in-eight independent FNV salt. Root wires exact sources and frozen wayhouse ID.

Capture is inert: seeded roll shapes, stock/loadout counts, original coordinates, haulables and next RNG identical with capture off/on. Only late successful relocation changes locations; no identities/stock/stats/factions/AI/RNG changes. First legal generated Crate/Sack is chosen in generation order, never preferred contents. Shelter requires actual complete ordinary1–2 Scrabbler group plus cache, existing opaque cover and reachable bypass outside sight; no manufactured enemies.

All optional refusals return true from IZoneBuilder. Never regenerate/retry the zone to force the situation. Source/geometry preflight and fresh revalidation precede moves; one receipt consumed once. Restore only exact still-owned transaction owners on refusal. Cached/restored graphs and repeated calls cannot recompose.
