## Recommendation

Implement one small source composition, but simplify the original plan: **leave a real ordinary crate or sack where it spawned and use that container itself as the existing territorial actor's post. Move only the existing marlback into its guarding position.** The player can pass around it, heed its warning and withdraw, commit to taking the finite stock, fight, or exploit real obstruction/cover. No new stock, enemy, ownership/crime system, quest, scenery stamp or general encounter framework is needed.

The original two-move/three-source design is more machinery than the visible outcome requires. The existing territorial Part already accepts any current non-creature ground object as its Post, including a crate. Using the cache as the center also solves a real interaction-depth problem with the proposed geometry. Keep the original wider mover design only as a separately justified follow-up if the native source census proves the stationary version cannot produce an ordinary encounter; don't implement both in advance.

## Scope and effort judgment

**Worth doing:** it gives an already shipped territory behavior a finite concrete reason to engage, and it gives existing cover and movement tools a context. It should be one reversible content slice plus tests/readout, not a combat-AI overhaul.

**Not worth doing in this milestone:** a three-owner/two-move compositor, a generic encounter graph, new reward tables, arbitrary loot rarity guarantees, loot payment changes, a theft reputation subsystem, counter-claim diplomacy, per-turn cache scanning/refilling, or bespoke art before actual native encounter evidence. If the stationary native candidate rate is genuinely inadequate, return that evidence and make one bounded source-design decision; do not hide scarcity with retries or a forced blueprint spawn.
