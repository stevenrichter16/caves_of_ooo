# Claimed supplies: implementation-readiness audit

2026-10-09. Read-only source design during the A/B native Play freeze. No Assets or repository living-doc edits, native runs, new source witnesses, or implementation are claimed here. Starting design: Docs/ENCOUNTERS-CLUES-AND-FINITE-SUPPLIES.md milestone C and Docs/Verification/QudEngagementAfterItemUtility/EncounterClueDesign.md milestone1.

## Recommendation

Implement one small source composition, but simplify the original plan: **leave a real ordinary crate or sack where it spawned and use that container itself as the existing territorial actor's post. Move only the existing marlback into its guarding position.** The player can pass around it, heed its warning and withdraw, commit to taking the finite stock, fight, or exploit real obstruction/cover. No new stock, enemy, ownership/crime system, quest, scenery stamp or general encounter framework is needed.

The original two-move/three-source design is more machinery than the visible outcome requires. The existing territorial Part already accepts any current non-creature ground object as its Post, including a crate. Using the cache as the center also solves a real interaction-depth problem with the proposed geometry. Keep the original wider mover design only as a separately justified follow-up if the native source census proves the stationary version cannot produce an ordinary encounter; don't implement both in advance.

Require at least one actual starting line of sight from the guard to a reachable loot contact so this doesn't become a wholly decorative guard; retain other blocked contacts as an earned cover route. ## Meaningful native tests, written before production

- **Selection/save:** version16 at most two selection rows, deterministic and no family/quiet/topology change;15 remains loadable and byte-equivalent/no new branch; same seed different WorldKey is not source authority; reading selection cannot generate/cache zones. CurrentVersion bump has explicit previous-version acceptance test.
- **Positive ordinary composition versus absence:** one exact original actor and stocked cache, cache never moves, same contents/IDs/Parts/count and RNG tail, role.Post is the real cache. Paired missing/empty/locked/foreign cache, wrong source count, wrong family/version/receipt/factory, and exhausted source. Preserve old territory path only before any claim.
- **Geometry:** all cardinal loot contacts lie strictly inside perimeter, at least one reachable; guard never occupies the only contact; bypass avoids entire watched region; no sole-lane or arrival/stair/reservation claim. Pair a reachable covered contact and observed contact; actual actor LOS behavior remains native.
- **Transactions:** callback replaces either producer receipt, cache/ContainerPart/child of same ID or actor role; outer commit refuses; callback claims actor origin or relocates actor. Preserve original stock and independent changes; no successful half-layout or fallback after claim. Check final-generation callback also invalidates changed geometry/source.
- **Gameplay commitment (not just coordinate assertions):** equal-speed player enters at shortest observed contact, hears warning, takes real native container stock via the same popup/take-all turn contract, attempts withdrawal; validate actual warning/action order. Counter: early withdrawal stays peaceful, no-stock failure consumes no pickup turn, outside bypass stays peaceful, opaque cover blocks the guard's real observation. Do not promise all builds pay the same risk.
- **Aftermath:** actual container transfer, empty revisit/reload, post destroyed/removed and returned, original exact live role saved. No regenerated owner, refill, synthetic reward or new personal hostility merely for entering/withdrawing. Existing native defensive-bump coverage must still pass once enforcement begins.
- **Honesty:** controlled geometry proves contracts; actual cohort proves only its sampled source occurrence; native Play proves the witnessed route and payment, not universal balance or all-seed guarantees.

## Scope and effort judgment

**Worth doing:** it gives an already shipped territory behavior a finite concrete reason to engage, and it gives existing cover and movement tools a context. It should be one reversible content slice plus tests/readout, not a combat-AI overhaul.

**Not worth doing in this milestone:** a three-owner/two-move compositor, a generic encounter graph, new reward tables, arbitrary loot rarity guarantees, loot payment changes, a theft reputation subsystem, counter-claim diplomacy, per-turn cache scanning/refilling, or bespoke art before actual native encounter evidence. If the stationary native candidate rate is genuinely inadequate, return that evidence and make one bounded source-design decision; do not hide scarcity with retries or a forced blueprint spawn.
