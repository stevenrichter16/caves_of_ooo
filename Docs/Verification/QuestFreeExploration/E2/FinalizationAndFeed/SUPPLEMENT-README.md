# Actor placement finalization and meal gesture supplements

Private, reviewed candidates after the published 101-case role/placement unit. No native success claim.

`CaptureFinalGeometry(Zone, Entity)` is an ephemeral cold-generation query. It captures the accepted actor-blocked critical-coordinate component relation, exact configured role and source anchors. Later queries reconstruct physical geometry and require the original critical routes plus the territory bypass or both actual crop-row approaches. A harmless off-route wall remains allowed. Splitting a former connected component, closing a captured border mouth, blocking a food approach or changing source/actor rejects. The delegate is not saved, used on live turns or allowed to mutate/replan.

The caller separately retains plan/receipt authority and its final source packet. Root owns `CaptureFinalState` and strict final generation acceptance; this helper does not define the manager commit policy.

Actual private geometry TDD: 14 missing-method RED with 49 placement controls, then115/115 combined role+placement GREEN. Latest files are listed in final-geometry-manifest.json; both runtime and test-assembly reference compilations passed.

The meal supplement uses the renderer-owned typed `EntityVisualHooks.EmitInteraction` API. `Fed` and exact row stubble remain committed before presentation. After the pre-existing dirty callback, it rechecks the same role, living actor/Brain, meal field, reserved field and original positions before emitting exactly one interaction. The operation creates no item, healing, damage, time, attack or extra actor action. Callback-owned changes remain untouched, and canceled/stale presentation does not undo a consumed meal.
