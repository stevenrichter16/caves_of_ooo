# F11 feasibility hypotheses, before execution

Scope: plan and source audit only; private core probes may establish current contracts. No production, shared source, Unity or Git changes. Root must approve a concrete plan before implementation.

1. Existing healthy ReedbackGrazer flight is scoped to Player/current hostility and a three-cell radius; a neutral Beast hunter will not trigger it without an explicit paired relationship. Counter: a nearby ordinary player or actual hostile triggers a real healthy step away.
2. Generic KillGoal may chase the current hidden target coordinate rather than last seen position; sight-breaking terrain therefore requires a scoped bounded pursuit role. Counter: a target without a current zone anchor should end the goal.
3. Existing sight obstruction comes from actual IsSolid/Wall semantics; a physical-only Hedge is not meaningful visual cover. Counter: an actual opaque Tree or Wall interrupts the native line-of-sight routine.
4. Current grazer death can produce a native corpse with source provenance but no authored harvest yield. Independent death loot is a separate economic path. An actual kill may legitimately leave no corpse. Counter: configured corpse chance0 cannot create a corpse.
5. A role extension must respect ordinary combat, party/service/pacification, current ownership and one paid AI action. Existing BrainPart/part callbacks and save serialization determine the smallest safe seam; do not assume a new BoredGoal variant can override active combat or survive reconstruction automatically.

6. Healthy flight uses greedy cardinal/diagonal steps, so a blocked directly-away cardinal step can idle despite a free side exit. Paired open step is the control. This is a scoped F11 design constraint, not a mandate to rewrite all AI pathing.
