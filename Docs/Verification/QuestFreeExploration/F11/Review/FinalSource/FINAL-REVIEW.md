## Actual performance contract

The final grazer uses lazy per-owner nonserialized queues/sets containing only coordinate values, preserves the old BFS ordering/scoring and clears them before movement can invoke callbacks. Whole-stack pacing admission uses existing indexed access; predator eligibility uses an equivalent loop. The final enum check explicitly accepts all nine declared values and rejects every other value, preserving saved bounds and terminal semantics.

There is still one measured native allocation event in each warmed flight path, so this is not zero-allocation and no such claim should ship. The scoped nearest-threat predicate remains; a broad neighbor rewrite is not justified by this now-passing budget. The cold source composer uses bounded one-time collections and cannot be mistaken for a per-turn cache. Scratch contains no entity references and never decides source or saved-state authority.

Native source evidence is real and calibrated: the original supported counter RED measured 21/27 events (ordinary/pacing). Stage4 reduced that to 3/5 and correctly remained failed. Stage5’s native RED measured 2 events in direct phase validation; its 28/28 GREEN measures 0 there and 1/1 for the actual warmed paths, below the unchanged ceiling 4. Empty/single/five controls still return 0/1/5. Private .NET bytes and native event counts remain separate metrics. The earlier zero-returning native managed byte counter and timing-valued probe results are invalid for native bytes and remain retained as such.
