# F11 generation test assembly correction

The original private all-in-one runner admitted internal gameplay members because its tests and gameplay compiled together. That validation was insufficient for Unity's separate `EditModeTests` assembly. The retained native capture and independent before-reference compile contain 29 CS1061/CS0117 errors; this is **invalid feature RED**, not an executable failing-test result.

Only three of the seven generation fixtures change. Twenty-seven direct `Entity.SpatialZone` reads now use an exact reflected field read; one `DoorPart.IsBareGround` call and one `SpreadExplorationPlan.Rank` call now invoke their exact internal methods through reflection. Helpers live in the existing `HuntFixture`, matching the project's native-test pattern. Assertions, source identities, callback conditions, expected values, test count (78), existing metas and production visibility are unchanged. All seven preimages match the immutable original final-test package.

A full reference compile using Unity 6000.3.4f1's bundled compiler and the current actual Bee response files reproduces 29 errors before the correction and exits 0 for both `CavesOfOoo` and `EditModeTests` after it. The script preserves assembly names, defines, references and complete source lists, changes only private output paths/test overrides, and references the freshly compiled private gameplay assembly from tests. It neither invokes Unity nor writes shared files. This proves assembly accessibility and compilation, not native execution or census success; the root must now run executable native generation RED before adopting generation production.

The pipeline fixture additionally resolves its census output folder once per census invocation. An explicit `COO_HUNT_CENSUS_OUTPUT` still wins. With `UNITY_EDITOR` and no override, the default is `Docs/Verification/QuestFreeExploration/F11/NativeCensus/<UTC timestamp>-<GUID>`. The same resolved folder receives `selection-before-generation.json` before any `GetZone`, and `census.json` after every evaluated selected address including declined rows and again with final totals. Each invocation gets a separate folder, so a full-suite run cannot overwrite earlier selection/results. Test output prints the resolved path. This does not set environment variables or content overrides, alter source selection, or affect gameplay RNG. Non-editor private runs retain opt-in output behavior. An assertion/exception still stops the census rather than inventing outcomes for addresses not evaluated.

The original package and before snapshots are retained; `testdelta-manifest.json` uses current shared preimage hashes. No production, editor, Git, or shared-file mutation was performed by this agent.
