# Native voxel mesh conversion — verification sweep

Status: mesh/art gates complete; final full regression is baseline-neutral and final GUID audit passes. Parent completed the corrected bake and native audit. This subtask did not launch Unity or modify existing source art, importers, materials, presenters, gameplay, camera, or native collision.

## Verified premises and corrections

| Assumption | Verified source | Implementation consequence |
|---|---|---|
| Imported mesh coordinates are metres | Existing FBX/prefab hierarchy may carry import scale; callers position entire prefab instances | Derive local voxel pitch from the effective prefab transform scale, record both pitches, and share one deterministic result per source Mesh reference. |
| Every mesh is CPU-readable | `SpawnRing3DAssetBuilder.cs:209`, `MultiCellPilot3DAssetBuilder.cs:214`, and village character importer metadata disable runtime readability for skins | Conversion happens explicitly in the editor outside play mode; no importer rewrite to enable readability. Editor-only `MeshUtility.AcquireReadOnlyMeshData` can bypass the flag if needed. |
| Vertex colors preserve existing palette | `Village3DCommon.hlsl` has POSITION/NORMAL/UV but no COLOR | Retain material/submesh slots; transfer source palette UV to voxel surfaces and emit separate flat-normal corners. No material or shader rewrite. |
| Replacing a character prefab is necessary | Existing skinned renderer stores bones/rootBone and mesh bindposes separately | Replace only `sharedMesh`; copy bindposes and assign a single dominant bone to each voxel. Keep internal joint faces between different bones so posed limbs do not expose uncapped cuts. |
| A mesh can be mapped repeatedly without harm | Applying source→voxel then voxel→other would change appearance on every call | Reject chained/cyclic mappings; `Apply` is idempotent and leaves unknown meshes alone. |
| One mesh per source is enough for all draw calls | Existing runtime combines static template meshes into patches | Expose both `Resolve(Mesh)` for patch source meshes and `Apply(GameObject)` for hierarchy instances. No runtime voxelization. |
| A triangle bounding box adequately preserves silhouette | Open diagonal planes and thin props contain substantial empty bounding volume | Use triangle/voxel overlap testing for the surface fallback and oriented ray intervals for closed interiors. Test separated solids and open triangles. |
| Filling closed meshes may use parity without care | Assets may combine intersecting outward-oriented primitive components | Accumulate oriented winding crossings so overlapping components remain solid; reject unbalanced open scanlines for filling and retain sampled surface cells. |

Relevant reference for non-readable editor access: [Unity MeshUtility.AcquireReadOnlyMeshData](https://docs.unity3d.com/ja/current/ScriptReference/MeshUtility.AcquireReadOnlyMeshData.html). Source mesh data, material assets, rig/controller/socket hierarchy, and colliders remain borrowed and unchanged.

## Final mesh scope and rationale

- `Assets/Scripts/Presentation/Rendering/VoxelWorldMeshCatalog.cs`: runtime `Resolve(Mesh)` and idempotent `Apply(GameObject)` only swap references. Unknown meshes, materials, colliders, hierarchy, animators, sockets, and bone bindings stay intact; skinned motion bounds are preserved and enlarged only when the new bind mesh requires it. Validation finishes before instance mutation. Serialized source bindposes permit validation when imported source meshes have no readable CPU arrays.
- The same file's `VoxelWorldMeshBaker` is an offline deterministic helper, not a runtime presentation dependency. It combines closed-volume scanline filling with triangle/voxel SAT surface coverage. Occupied voxels become outward flat quads; greedy merging respects UV palette, submesh and rigid-bone boundaries. Surface cells retain source palette coordinates; neither materials nor texture import settings change. The current import metadata explicitly caps skin weights at four, matching the sampled legacy weight format. Blendshape sources fail explicitly rather than silently losing animation.
- `Assets/Editor/Art/VoxelWorldMeshBuilder.cs`: collects all village, ring, pilot and shared equipment prefabs; consolidates repeated Mesh references; derives 0.125/0.2 metre pitch from effective prefab scale; converts offline; preserves source submesh coverage and bindposes. Stages the complete conversion before writing owned output meshes and publishes the resource catalog last. Existing output GUIDs and all borrowed prefab/FBX/material/importer dependencies are checked. No runtime voxelization, importer readability rewrite, global renderer modification, or source-prefab replacement occurs.
- `VoxelWorldMeshTests.cs` and `VoxelWorldMeshAdversarialTests.cs`: protect geometry, topology, skin, material slots, invalid inputs, deterministic generation, source immutability, instance-only replacement, transform preservation, and atomic failure. Additional path-key cases are owned by the independent presentation reviewer.
