## Why unchanged reuse is the first choice

The actual five source sheets are crisp64×384native sheets containing16×24cells.
The selected South-idle frame is Unity rectangle `(0,360,16,24)`. The original
pixels use five visible colors for each snake and six for each frog/tortoise,
with hard alpha edges. Their contained silhouettes and limited palettes are
compatible enough with the approved cast's compact pixel language for a real
trial. They contain more small outline/detail marks than some broad cast shapes;
that is a normal-zoom comparison item, not proof that redrawing is necessary.

The frog pair's alpha masks are not identical, and neither are the two snakes',
but each pair has a similar body plan. Palette and small shape cues therefore
need a paired actual-world check. Color differences alone in enlarged source
sheets do not prove distinct live silhouettes under regional grading/status.
Do not recolor the source to match the current glyph tint: the proposed native
palette is intentional, while actual hurt/status cue overrides remain essential.

The agreed minimum is direct borrowed texture reuse with five cached, centered
Sprite/Tile pairs, using the existing source imports and authorized world/reader
routes. No new atlas or PNG extraction is needed. Full PNG/metadata and selected
cell pixel hashes are recorded in `Docs/GRAPHICS-STUMP-FAUNA.md`; originals,
metadata and legacy animation remain unchanged. The existing sprites are already
native source material. A new drawing or imagegen correction is justified only
if an actual after comparison exposes a named silhouette, contrast, scale or
identity defect; it is not required merely to create another asset packet.
