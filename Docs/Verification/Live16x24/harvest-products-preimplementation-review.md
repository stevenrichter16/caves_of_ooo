## Meaningful implementation risks sent before production

1. **Known-role refusal must survive local routing.** `FlatPixelGreyboxCatalog.cs:884–886,954–956` can still call `_openingArt.TryResolve` in local graphs after a new adapter refuses. `FlatPixelOpeningArtCatalog.cs:540–563` has weaker legacy ItemFrameOf checks, and WorksProductFrameOf also lacks the proposed sole-part/status/footprint policy. For example, a stricter new adapter could reject an effected/duplicate-part reused Mushroom or malformed FireClay and then the local legacy route would paint it anyway. Let the exact17-role route own success and refusal in both world and reader paths, or narrowly align those17 legacy branches; do not expand global admission or alter unrelated items. Include a paired local/nonlocal counter and missing injected reuse-resource counter. This is a preimplementation integration hazard, not a claim of a defect in unimplemented code.

2. **Preserve successful output through later optional resolvers.** World routing reuses `out art` across several branches. The recently fixed Sodden/Beating branches use separate outputs because an optional miss can otherwise null earlier success. Give this portable product result its own slot or route it after competing regional branches, then verify full and dirty actual submission. Raw resolver success alone is not painted evidence.

3. **Avoid false required parts and mutable-stat hardcoding.** Do not require Material/Thermal, layer5 for GroveRed, SeedPart for StoneburrSeed or MineralPreparation for Tepuibone. Do not bake Commerce.Value, weight, Healing dice or current stack count into identity. Require owned positive bounded stack and the actual semantic parts without freezing changing values to defaults. The old equipment `Owned<T>` helper checks only the first part, so it does not by itself satisfy the new sole-owned-part contract.

4. **Match mechanic token semantics without repaint side effects.** Reagent.GetProperties lowercases/trims and caches by raw snapshot; reordered/whitespace-adjusted meaningful properties should not fail merely because a raw string differs. GroveRed must keep positive toxic as well as vital. PreparationRecipePart.Allows currently matches exact comma-separated tokens without trimming; substring matches such as `not_bandage` must not authorize a cord recipe. Avoid allocating Split/creating recipe dictionaries or invoking preparation actions in each art query. Read owner color override through owned StatusEffectsPart without firing Render events; effect counter fixtures must assert their effect actually applied.

5. **Reader authority is already correctly separated in the plan.** Public BuildInventory/IsCurrentSubject binds real custody and retained documents; ZoneRenderer/ExaminePortraitRenderer additionally bind the actual current presentation graph. A carried product has no SpatialZone and is still legitimate. The semantic adapter must not require world occupancy for carried items, while tests must use the actual public document route for disclosure claims and reject stale custody/graph. `Entity.SpatialZone`, `PreparationRecipePart.Allows` and `PreparationRecipeService` are internal: external test assemblies should use public `Zone.GetEntityCell`, public RecipeIds plus observable actions, or deliberate reflection rather than direct inaccessible access.
