## Minimum production diff

Expected runtime file: **`Assets/Scripts/Presentation/Rendering/FlatPixelSoddenTravelCatalog.cs` only**. Existing `FlatPixelGreyboxCatalog.SoddenTravelArtFor` (`:955-963`) already calls the public scope predicate for foreground, ground and reader paths; it should need no new dispatch, atlas or duplication.

1. Add one small immutable finite coordinate lookup inside the catalog, constructed once from the authored20×20 map. Keep canonical ZoneID keys and coordinates only. Include an address iff it is one of the three `SoddenDistrictPlan` IDs or `SoddenCompositionPlan.IsWildernessZone(id)` is true. Static ordinary indexing includes the three district IDs, so do not double-count them. Use `StringComparer.Ordinal` and `TryGetValue`; no negative-cache growth for arbitrary caller strings. This is address metadata, not cached authority.
2. `IsSupportedZone` first requires non-null zone, non-null canonical ID present in that lookup. Preserve real receiving context, exact cached-graph identity and map-array shape checks. Check the **lookup's actual(x,y)** in the current map each time: Sodden and no POI. Add `!LairStacks.HasSavedColumn(manager, zone.ZoneID)`; apply this to the shared admitted scope so a stale saved lair never borrows the district exception either. This adds a narrow saved-authority refusal without altering normal district behavior.
3. Do not cache biome/POI/lair approval. A newly added POI, changed map biome, replacement graph or saved ledger must revoke qualification even after warmed lookups. Do not call `GetZone`, `GenerateZone`, `FormationSelector`/`Create` during paint, `SoddenDistrict.Eligible`, `AreaCompositionScope.Allows`, `LairStacks.Inspect`, `TryPlan`, `BindForSave`, or `Restore` from the renderer.
4. Leave `ForegroundFrame`, `PlainOwner`, `Owned<T>`, `HasForeignMeaning`, `NeutralThermal`, `CompetingGround`, substrate selection, native-frame variation, borrowed texture lifetime and disposal unchanged unless an actual failing counter exposes a specific defect. Keep remembered/hidden owners on fallback. Every newly eligible frame must still pass those exact guards.
5. Update the catalog summary/comment to say current district plus ordinary Sodden material graphs. Do not rename resources or the kit simply to reflect wider reuse.

Why a finite coordinate lookup: current address shortcuts are allocation-free but only work for three IDs. A positive-only table of at most400 coordinates is bounded, source-grounded and independent of mutable world state. Reusing a currently existing equally strict allocation-free address helper is also acceptable, but do not build a general region-admission framework for this slice.
