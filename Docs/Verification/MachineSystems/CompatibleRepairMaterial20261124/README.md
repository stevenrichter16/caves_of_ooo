selected first, including legal cellar clay with its original provenance. The
alternate grade requires an authored, unchanged, portable commodity. Raw clods,

clay allocation stays spent and existing serialized cook shelves stay literal.

reinsert material into the dead actor's pack. A callback that also forcibly
moves the actor can leave a different spill cell outside this narrow recovery.
