# Polished menus and popups

The existing World Actions, container picker, pickup, ability list,
quest journal, faction standings, world log, field notes and readers,
pause and its graphics/audio pages, starting build, spell effects,
throw picker, and attack confirmation use the same styled card.
The shared view lays out text, state, rows and key badges inside
the gameplay area. The menu controllers still own the choices, target
identities, ledgers, action authorization and timing.

The real settled catch was visible on the same original tray. The new
World Actions menu opened its field notes, restored the same Gather
selection on return and added one vent scale through ordinary input
at tick 3620. Browsing menus held at the current tick. I also dropped
the carried scraper and tray, opened Pickup, inspected one, and took
both with the normal one-turn operation at 3630. Cargo identities and
the exact vent catch remained observable in the native receipt.

Native 445 cases passed, including all 444 menu and action
checks. The adjacent spell-art catalog checks still report the registered
spell count difference (expect 49, see 51). The six new tests failed on the
old menu configuration and passed after the change. Coverage includes
native positioning, pointer and keyboard agreement, exact actions,
disabled rows and item choice behavior. Four older assertions used
outdated reflection arguments. Their fixtures now invoke the current
trade and visible-surface readers with their explicit parameters.
The native performance audits now read the painted key badge.

The Editor left Play Mode. All 880 normal Quick files and 87 unrelated
tracked files matched their pins. The spell settings trial wrote default
preferences on close. The original values were restored. One preference
file was serialized differently. With the final change, opening and
closing Spell effects without adjustment does not save preferences.

## Mac build

On Apple M5, the packaged game reproduced World Actions, the selected
action reader, the actual tray catch, the ability list and graphics
settings. A second launch previewed the new starting build choices.
The original test save and both current preference file pins were
exact after both runs. The isolated Editor preference observation
above has its own earlier baseline. The spell catalogue count
