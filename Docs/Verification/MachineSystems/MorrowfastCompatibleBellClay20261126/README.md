# Delivered clay quiets Morrowfast’s watch bell

The same verified lining clay already used for fired wells and batch pans
now works for the watch bell’s quiet sleeve. One measure sets the same
quiet mode. Ordinary fire clay has priority if both forms are carried.
The bare setting is free and sends a call farther. Switching back to quiet
requires a fresh measure.

This was one guided regional transport connection using an earned checkpoint.
Earlier native evidence covers the ordinary fire-clay path and the existing
quiet and bare behavior. The new native suite independently checks both
materials, ordinary priority, noncanonical payloads, wrong grade and invalid
custody. The initial run reproduced the prepared-clay refusal. It also found
that a guest-rest test depended on a clock from another fixture. Giving that
test its own clock verified the hostile refusal and 60-tick rest. All 49
final connected native cases passed. The full regression remains open.
