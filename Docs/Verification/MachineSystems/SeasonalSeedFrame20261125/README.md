# Late knotflax and the public frame

November 25 UTC, 2026. Local candidate. Independent reviews found no remaining
blocking source or recorded-play issues in this slice. Combined publication and
the Mac package are pending.

Fresh version 21 allotments can place one nonblocking knotflax stand near the
two existing Morrowfast rain frames. The stand gives one seed-head bundle in
phase 1 of the saved regional calendar, the second eight-day phase of the
prototype cycle. The Examine reader describes the ripe heads. Gathering
spends the stand. The bundle can be carried and cleaned after that phase ends.
The existing frames each accept the exact bundle for one ordinary knotflax
seed, with dry chaff discarded. The work takes one action and uses no water.
The seed needs an ordinary prepared bed. The original crops, purchased seeds
and manual watering are available in the same field.

operation. Later counters reproduced unrelated screening being disabled by
missing optional content, stunned direct dispatch and a fatal observer
interrupting each new action. Missing content now omits the optional work.

and frame work, so a later observer cannot undo paid work or duplicate a
death drop. Existing recipes retain their prior notification timing.
