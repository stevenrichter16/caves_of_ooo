# One fallen branch supplies seasonal timber

Freshly generated Gleaners' Glade can offer one usable length from a
fallen branch near the fire. Fair weather early in the growing cycle
and dry ground make the length visible and available. Cutting it
takes one action with a sound carried or equipped wood-cutting tool.
The branch leaves a visible cut mark and the tool stays with the player.
The one ordinary salvaged timber can serve existing material demands.

## From the Tine shelf to the Glade

A fresh isolated game used seed 2. The traveler took the
ordinary atlas route to Tine and met Vellin Mosswick with 50 drams.
The ordinary trade menu transferred the exact hatchet `7420` for
28 drams. The traveler had 22 drams and 40 HP at tick 380.

The traveler returned by the atlas and stood at `(43,9)` at tick 530.
The branch `2715` stood directly north on its original grass.
Ordinary waits to tick 1200 brought the season's next shower and
removed the cut choice. At the next fair window, tick 1800, the same
branch offered the cut again. One action made one board `7518`, put
it in the pack and left the same source spent.

In a separate replay from the bought hatchet save, the view stayed
on the same tile through the 1190-to-1200 weather change. The bright
double stroke immediately north of the traveler became a muted
single stroke as the shower began.

The existing **Shape haft** action used that board at tick 1820.
It made one rough field haft `7519`. Fresh Continue kept the exact
haft, the bought hatchet, the spent branch, 22 drams and 40 HP.
The saved object still opened its ordinary inventory reader.

## Native cases

The five feature cases initially found no generated branch and ten
existing controls passed. A second baseline reproduced a cut offer
over a water coating. The final 99 cases passed. They cover the fixed
source and retained scar, season and rain, local dry footing, a wood
tool and a flexible-stock countercase, and saved hatchet capabilities.

Independent source and gameplay review checked the tool receipt,
weather, exact product and all 16 saved-file pins. The Editor restored
the checked input and save settings. All 876 normal Quick files and
87 unrelated tracked files matched. About 130 MiB was available on
the build volume. The latest verified standalone Mac package is
`2c4931acc`.
