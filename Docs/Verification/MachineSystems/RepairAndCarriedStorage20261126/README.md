# Repair requirements and labeled carried storage

Examining a broken object puts an amber **Needs repair** section first.
The section describes the current fault, then lists the actual bill.
Known temporary patches appear separately from lasting repairs. Live
repair rules determine which materials are alternatives and which tools
are kept. A broken object with no supported repair method gives that
status without a made-up bill.

Ordinary seed 64 GameBootstrap play walked to the Gleaners' well and
used Examine. The warning showed two measures of fire clay or prepared
lining clay, in any mix. In the private equipment comparison, an exact
dagger with the ordinary Broken effect showed one steel blade and no
station through inventory F1. Native tests exercise the Tine weir's
retained hatchet, its distinct 150-turn temporary patch, and the absence
of the warning when the site is repaired.

## Carried vessels

From the inventory, open **Label storage** to select a swatch, choose a
colored icon, or enter short colored text. **Open contents** and **Stow
from pack** resolve the exact carried vessel. The shell and its contents
count toward the same pack weight. Existing loose Camp Boxes and new
Field Satchels support the first release.
