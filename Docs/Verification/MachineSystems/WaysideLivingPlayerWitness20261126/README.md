# Player testimony about the living Wayside porter

The player can freely note the exact visible worker assigned to an overdue
shipment. An available cook on a personal search can hear the historical
location in one action. He can check the place using his existing search
budget. His own sightings and the actual handover still have their separate
consequences. A firsthand body sighting can replace an unreported living
sighting. A personal search accepts one submitted lead.

## Editor play

This used the retained seed 64, generation 18 Wayside route at turn 300.
An earlier audit had applied a controlled Rooted delay to the original
porter. The player used normal controls throughout this trial. Orven
independently saw the porter at turn 300 while the player approached. The
player's later report changed the route.

and reporting to a paid hand remain open.
