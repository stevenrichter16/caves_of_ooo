light commands never silently spend moss. Quote binds source ID/count, actor
origin/zone, exact target and finite target state. Exact reference membership
and coherent current physical owners prevent ID aliases or substitute stacks.

source custody, replaced identity or integer overflow is preserved with a limited
refund diagnostic rather than a guessed destination. The exhausted original body
can return to the pack only for the actual last-unit case. Target light/heat has
its own small inverse and post-payment/commit checks. No whole-actor rewind.
