# Tools in Inventory

Tools appears beside the other Pack tabs. Click it or press U from the
Inventory list. It shows what each accessible tool does, which work is
ready, and the conditions or materials each action needs. Up and Down
choose a tool, and Left and Right page through longer details.
Equivalent carried copies use the same counted rows as Inventory.
G shows the individual copies. Charges, contents, labels and condition
retain their own compatibility. An action still binds to one exact copy.

The view draws carried and equipped tools, cases in valid carried
storage, and stations that are visible and within ordinary reach. The
selected flask, scraper or other held tool opens its normal item action
menu. A stowed item can be taken into the pack. A placed tool opens the
world menu for that exact object. A material recipe can link back to the
same source row when it names the chosen tool and workpiece.

In the retained tray trial the player had a supplied scraper and two
supplied trays, one already standing beside original steam vents. The
new tab showed the carried scraper's needs, the carried tray's setup
state, and the nearby tray's ready catch. Browsing stayed at tick 3610.
Enter opened the standing tray's ordinary action menu. Gather put one
vent scale in the pack at tick 3620 and left three shared source catches.
HP stayed at 343.

388 focused cases passed in the final native run. They
covered exact flask ownership and payment, the particular sieve named by
a material quote, stowed and hidden controls, setup versus processing,
and the existing inventory and screening behaviors.

The mortar and pestle has no authored item or grinding process in the
current content. A tool with that capability can use the same item and
workpiece recipe paths once its process is authored.
