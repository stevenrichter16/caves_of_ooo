# Cured leather feed: bounded proposal

Status: source and ordinary-supply qualification only. No new runtime code, offcut stock, cutting capability or native tests exist. M3a and current Mac source1237eae9f remain accepted. This increment supports regional workshop materials into components; it does not establish raw-hide tanning or a complete processing machine.

## Player opportunity

The accepted Cinderhold loop demonstrated a real component cost: a finished leather binding costs23drams at Istren Fennit's finite stock; the earned character had15 and exchanged a10-value book plus13drams. That binding supplied+1Hit in an ordinarily assembled weapon. A sound cured-leather remnant offers a modest materials-versus-finished-work choice, with no new degradation tax. Players can keep or sell the remnant, buy a finished binding, use an existing plain-cord binding, use starter equipment, or leave the activity alone.

Existing consumers are source-verified. LeatherBinding grants+1weaponHit. The leather-equipment-stitch repair recipe consumes one binding for carried, unequipped singleton equipment with CompositionLeather, an eligible equipment Part and actualBrokenEffect. FilterHood, AcidworkerApron, ColdwardCloak and LeatherArmor opt in. No actually damaged eligible leather item was present in the earned baseline, so repair usefulness is not yet actual-play acceptance. Do not induce damage merely to justify this input.

A cured harness-leather remnant fits that mundane provenance; this does not establish a regional tanning tradition. Root Lore/README, Bible/SecondSpine and MysteryLedger remain authoritative; trade/workmanship details may use aligned material culture and Concord sources.

## Smallest candidate contract

One explicitly sized, sound, already-cured leather offcut yields one canonical existing LeatherBinding. Exact source weight/value and loss text need an economic/physical check against the output before native RED. No quantity is inferred from Material/Composition or a corpse tag. No original hidden child item or original identity is promised. A finite supplier should stock a small authored quantity through existing physical trade custody; completed bindings and other stock remain available. Prefer a generic supported supplier capability/stock packet over a site-only process permission. Never retrofit cached inventory or replenish on travel/reload.

The conversion is supervised cutting. A forge, new tanning station or compulsory machine is unjustified. It should work wherever a supported physical cutting capability is accessible. Carrying an existing dagger is a plausible ordinary alternative, but the game does not yet have a generic pack-cutting contract: do not treat a name, damage die or Piercing attribute as proof of flexible-stock cutting. Define a narrow reusable Part capability and exact reachable-tool policy only after independent critique; avoid an expansive universal tool framework. Future benches can supply the same supported capability when a real second use justifies it.

A proposed hand-tool path must pin the particular source, actor, accessible tool, definition, quantities, output metadata and capability state in the immutable quote. The shared executor owns permission, participant claims, source/output custody, one committed action, rollback and save stability. Before-veto and committed completion events apply to participating entities consistently. Tool loss, movement, transfer, capability removal, actor death, callback reentry or source mutation cannot bypass a stale quote or consume inputs on failure. Unknown instance behaviors need explicit safe policies; no silent state laundering through canonical output.

Keep ordinary crafting convenient. No tool wear, wall-clock curing, background job, mandatory upkeep or skill grind is introduced by this pilot. No generic cost/yield modifiers, arbitrary effect propagation or NPC autonomous planning is accepted merely by adding the recipe. Check current source/output material reactions before assigning new reactivity; do not advertise unsupported contamination/fire transfer.
