# Greatdew — original native source trial

One static neutral Greatdew body, authored as original named integer unit-quads in Blender 5.2.1 LTS. Source-only trial: no Assets PNG/importer, runtime, Unity or Git operation was performed by this artist. Root owns publication, native integration and actual gameplay review. This author’s visual observations are self-review; the separate vine reviewer viewed both contacts and found no source silhouette blocker, while explicitly reserving actual grading/owner/painter acceptance.

Inputs actually viewed: `greatdew-before-01-open-mire.png`, `greatdew-before-02-reader.png` and this folder’s `scene-reference-01.png`. The reference is an imagegen concept, not gameplay or production pixels. Its exact prompt is retained. No reference pixel was sampled, traced, cropped, rescaled or downsampled into the sprite. Python describes original geometry and validates Blender outputs; Pillow only decodes/checks images.

The actual blueprint is a non-solid, non-takeable Plant with 10 structural HP, cyan parenthesis glyph at layer2, Examinable and GreatdewSnare. The existing step-trigger has 55% grab chance, Rooted4 and Acidic corrosion1; it is not consumed. This packet changes none of those mechanics and does not depict armed, spent, grabbing, damaged or inactive states. A static pleasant-looking bead is not a new safe-state promise.

| Concept part | Native decision | Meaning boundary |
| --- | --- | --- |
| Hooked olive stalk | Tall asymmetric bent stem, open center, two-tone edge | One cell; no new collision or adjacent-cell grab |
| Clear sticky beads | Three separated asymmetric2×3 clusters, one pale reflection and darker mint underside | Glass-like impression with binary alpha; no light emission, aura or invented status cue |
| Basal leaves | Two narrow staggered leaves merging into the stem | No ground platform, extra vegetation or changed terrain |

Root’s pre-render critique rejected flower-like petal crosses/stars and a broad uniform arch. The final drops use compact asymmetrical five-pixel forms rather than radial crosses. No teeth, mouth, pitcher, flower, fake ground shadow or glow. The concept’s bright bead mass is reduced to restrained native clusters. Seven colors;16×24 canvas;84 opaque pixels; occupied bounds `[1,3,13,23]` (12×20); baseline y22 with row23 transparent. Pixel coordinates are top-left/y-down. FullRect centered pivot,16PPU, Point, no mips or compression are the proposed import contract, not an executed importer change.

Self-review at native size: the hooked stalk and three separate drops read on both dark grass and dark mire study backgrounds. Olive stem contrast, tiny bead material and static size must still be judged in actual graded world/reader captures. The two contact instances are the same single body on two backings, not two states. This small owner cannot resolve the broad sparse-chunk or mire hazard-salience debt.

Reproduce from the repository root (the builder writes only this source directory):

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --threads 4 --python Tools/Live16x24/build_greatdew.py -- --build
/Applications/Blender.app/Contents/MacOS/Blender --background ArtSource/Live16x24/greatdew/editable.blend --threads 4 --python Tools/Live16x24/build_greatdew.py -- --inspect-blend
python3 Tools/Live16x24/build_greatdew.py --verify
```
