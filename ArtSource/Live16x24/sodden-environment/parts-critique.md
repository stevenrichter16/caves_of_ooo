# Sodden environmental reference critique

AI-generated design study, not gameplay. Input: actual1280x800 `sodden-environment-before-01.png`, earned157, OpenMire18.8.0, turn2350HP38. Built-in imagegen output preserves broad composition but changes pixel density, small objects and some pool outlines; never use these as authoritative geometry.

Adopt muted moss/peat ground color, irregular flattened-sedge clusters, dark wet pool bodies with restrained horizontal surface marks, and readable inside-cell shore edges. Reject the uniformly dense microtexture, continuous bright rim, softened/non-native pixels and altered boundaries. Real ground must have quieter stretches; actor/reed/item contrast outranks texture richness.

Production: original editable native16x24 cells, no downsample/tracing. Separate576x24 atlas: four firm-ground variants, sixteen full-pool cardinal joins, sixteen depleted wet-film joins. N1/E2/S4/W8 joins mean disclosed valid wet neighbors; absence makes a shoreline within the existing cell. Pools remain hazardous wet film even depleted. No grass rendered into pool interiors, safe path markings, mud mechanics, props or collision changes. Retain existing genuine reeds and all shared Sill/travel sources.

The concept suggests a direction; only matched Unity before/after and actual movement/readers can establish the bounded improvement. Whole-biome acceptance remains open.
