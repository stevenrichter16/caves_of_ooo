## Critique and native extraction boundary

**Scene reference — accept:** muted mauve flesh against dark green; a slack
former-person outline, asymmetric limbs and one close tendril; small figures
belonging to the existing scene rather than a new encounter.

**Scene reference — reject:** its two figures differ in shape and scale, and
both contain more shading/detail than the native cast. The output changes image
resolution, re-renders HUD text and retouches terrain/fog. None of those changes
is authorized production work. Keep the actual map, camera, UI, original actors
and approved terrain unchanged; only an exact Shambler owner receives its new
body through the real renderer.

**Parts reference — accept:** small drooping head, forward-curved/slack torso,
two separated grounded legs, muted purple flesh and sparse gray-green patches.
The finite breakdown offers one body, not an asset-count requirement.

**Parts reference — reject:** oversized detailed clusters, broad shoulder mass,
soft/partially transparent generated edges and highlight strips. The tendril's
upturned pale end can read as a held cane; native construction must connect it
clearly as the one arm and end in a narrow unlit taper. Do not copy its pixels,
reduce this bitmap to16×24, keep its many intermediate colors or reconstruct a
staff, extra leg, mushroom cap, spore cloud, armor or equipment. The detached
parts are extraction guides only, never separate spawned objects.
