# Hedge continuity concept and extraction

The imagegen scene is design guidance, not gameplay evidence. Inputs are actual
Unity captures `hedge-before-court.png` and the normal-input corner approach
`hedge-before-corner.png`, seed 200893250, player 7,4, tick4500. The latter was
the imagegen reference. Prompt is saved alongside `scene-v1.png`.

Accept only continuous leaf mass, explicit L turn and quieter internal rhythm.
Reject the generated fine noisy leaves, soft/shaded pixels, changed sizing and
redrawn UI. No generated pixels are imported as runtime assets.

Extraction: one exact Hedge owner, neutral live state, sixteen cardinal masks
N1/E2/S4/W8. Four ends, horizontal/vertical runs, four corners, four T joins,
cross, and isolated original. Join cross-sections must match; absence must cap.
Native production uses editable integer cells/geometry and the established
olive/wood palette. Isolated mask0 and examine image retain the original
north-vegetation frame1 pixels exactly. No growth or damage stages are invented.

Retain actual one-cell gaps, lower ground, original owners/collision, approved
trees, characters, hives and court. Native contacts test joins, runs, turns and
real gaps before actual Play acceptance. Whole scene/region gates remain open.
